# InvNext - Sistema de Inventarios Inteligente 🚀

Backend en desarrollo construido con **FastAPI** y **MongoDB (Beanie ODM)**.

## Características actuales:
- Gestión de Órdenes de Compra.
- Recepciones de mercancía (totales y parciales).
- Creación automática de Lotes (Dinámicos por fecha y Perpetuos).
- Cálculo automático de Costo Promedio Ponderado.
- Protección de pagos a proveedores (evita sobrepagos).
